# AGENTS.md

Guidance for agents working in this repo. These rules override default behavior.

TypeScript StreamElements custom-widget wheel. Single esbuild bundle (`src/` -> `dist/wheel.js`), the playground/instructions page is generated by `scripts/build.mjs`, and `vitest` + jsdom cover the pure logic. Web Audio synthesizes all sounds; no audio files ship.

## Back-compat (highest priority)

- Old or partial configs must always render. Never hard-error on a missing or unknown field; fall back to a reasonable default so an existing user's widget keeps working after an update.
- New fields are additive with defaults. Do not rename or repurpose an existing field key in a way that breaks configs already saved in StreamElements or in shared config codes.

## Version control

- The repo is jj-colocated. Use `jj`, not `git`, as the authoritative interface.
- Never append `Co-Authored-By` or any AI attribution to commit messages.
- Make focused commits, one per logical change. Conventional-commit subjects.

## Types and data modeling

- Prefer newtypes/branded types over raw primitives for domain values (angles with their unit, durations, indices, weights). Let the type system reject mixing them.
- Model "absent" or "unlimited" with a union/`undefined` or an enum, never sentinel values like `-1`, `0`, or empty string.
- No heuristics. Resolve landings, weights, and geometry from the model, not from guessing on rendered strings or measured pixels where the model already has the answer.
- Bubble `Result`/`undefined` up to the boundary that has enough context to handle it.

## Comments

- Comments explain non-obvious intent only. Terse, DRY, WHY not WHAT.
- No salesmanship or filler. No historical framing ("now X", "was Y"). Describe current behavior.
- No numbered step-recaps of the implementation.

## Text and formatting

- ASCII only in code, comments, UI strings, and commit messages. No emdash, endash, ellipsis, arrows, curly quotes, or other unicode symbols. Use `-`, `--`, `->`.
- No separator or banner comments. Structure with functions, modules, and blank lines.
